# Yuvraj Digital Studio — Build-First Micro-Site Engine (Kathmandu & Pokhara, Nepal)

A complete multi-tenant Next.js + Supabase production platform powering **8 bespoke, conversion-engineered websites** for verified businesses in **Kathmandu** and **Pokhara**, complete with:

- **8 Custom Industry Experiences:**
  - `/evoke-jhamsikhel` — **EVOKE Cafe & Bistro** (Jhamsikhel, Kathmandu)
  - `/apple-dental` — **Apple Dental Clinic & Orthodontic Centre** (Panipokhari, Lazimpat, Kathmandu)
  - `/smile-signature` — **Smile Signature Nepal** (Blue Note Building, Lazimpat, Kathmandu)
  - `/advance-paragliding` — **Advance Paragliding Pvt. Ltd** (Lakeside St. 7, Pokhara)
  - `/green-spa-pokhara` — **Green Spa Pokhara Lakeside** (Lakeside St. 14, Pokhara)
  - `/le-spa-pokhara` — **Le Spa by Donaldji** (Fewa Times Square Level 3, Hallanchowk, Pokhara)
  - `/rosemary-spa` — **Rosemary Spa & Beauty Home** (Lakeside St. 16 Centerpoint, Pokhara)
  - `/meditouch-pokhara` — **MediTouch Skin & Hair Clinic** (Pokhara)
- **Preview Mode (`?preview=1`):** Displays a non-intrusive floating claim bar + silently logs owner link opens to Supabase (`earning1_businesses.owner_view_count`).
- **Zero-Code Custom Domain Handover:** Add any client's `.com` / `.com.np` / `.tech` domain in Vercel + bind it in `/dashboard`, and `/` automatically serves only that client's white-label site.
- **Founder CRM Console (`/dashboard`):** Real-time open tracking, test booking feed, 1-click WhatsApp follow-ups, and custom domain binding.
